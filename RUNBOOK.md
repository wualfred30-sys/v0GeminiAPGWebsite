Gemini Aviation Academy Runbook

## Configuration

This is a static Next.js application with no backend services. No secrets or environment variables are required for deployment.

### Common Tasks

#### Monitoring Application Health
Verify the application is running by loading the homepage or checking the Vercel deployment status. You can also use the `/api/health` endpoint.

#### Updating Content
Content is managed by updating React components in `src/app` and `src/components`.

## Deployment

The application is deployed as a standard Next.js app.
Ensure the build command `npm run build` succeeds before deployment.
